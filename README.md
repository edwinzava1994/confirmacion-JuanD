# 🎉 Confirmación de Juan 🎉

Este es un sitio web creado especialmente para celebrar la confirmación de **Juan** 🚀.  
Aquí podrá recibir su regalo digital de forma interactiva.

---

## 🌐 Acceso al sitio
Puedes entrar al sitio en este enlace:  
👉 [Confirmación de Juan] - (https://edwinzava1994.github.io/confirmacion-JuanD/)  

## 📲 ¿Cómo funciona?
1. Abre la página desde tu celular o computador.
2. Lee el mensaje de bienvenida ✨.
3. Selecciona dónde quieres recibir tu regalo:  
   - 💳 **Cuenta de ahorros**  
   - 📱 **Nequi**
4. Ingresa el número correspondiente.
5. Haz clic en **Enviar** y se abrirá automáticamente WhatsApp con un mensaje prellenado.
6. ¡Listo! Solo toca enviar el mensaje para reclamar tu regalo 🤑.
